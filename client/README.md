# Vertexa client

This is the React/Vite frontend for Vertexa.

For local development, copy `.env.example` to `.env` and set
`VITE_CLERK_PUBLISHABLE_KEY` and `VITE_BASE_URL`. Run `npm run dev` from this
directory.

Vercel setup, API deployment, and production environment variables are
documented in the repository [README](../README.md).
